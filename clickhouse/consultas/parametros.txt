# parametros.txt -- LOS UMBRALES DE LAS CONSULTAS DE clickhouse/consultas/, EN UN SOLO LUGAR
#
# Las consultas usan parametros de ClickHouse, {nombre:Tipo}. Es el mismo
# formato que recibe el driver de Node del backend (query_params), asi que el
# backend puede copiar el texto de cada .sql sin tocarlo. Aqui van los valores
# que se proponen; el arnes (clickhouse/correr_consultas.sh) los pasa como
# --param_nombre=valor.
#
# Una linea por parametro: nombre=valor. Las que empiezan con # no cuentan.
# Los que dependen de QUIEN pregunta (usuario, sesion, producto, candidatos) no
# van aqui: los pone el backend en cada llamada, y el arnes en cada prueba.
